# Genshin Character Catalog

Навчальний проєкт із дисципліни «Об'єктно-орієнтоване програмування»: каталог персонажів із ізольованим шаром бізнес-логіки (`CORE`), системою локального кешування зображень (`DATA`), сервером `Express Web-API` та графічним інтерфейсом на `React`.

---

## Запуск для користувача (Release-версія)

Готовий до роботи застосунок упаковано в єдиний автономний виконуваний файл, який не потребує встановлення `Node.js` чи додаткових залежностей.

1. Перейдіть у розділ **[Releases](https://github.com)** цього репозиторію та завантажте файл **`genshin-character-catalog.exe`**.
2. Запустіть завантажений файл подвійним кліком.
3. Відкриється консольне вікно локального сервера (`http://localhost:3001`), після чого автоматично відкриється вікно браузера з інтерфейсом каталогу.
4. Для завершення роботи застосунку закрийте консольне вікно або натисніть `Ctrl + C` у ньому.

> **Примітка щодо зберігання даних:** локальний кеш завантажених портретів персонажів автоматично створюється у директорії профілю користувача (`~/.genshin-character-catalog/cache/images/`), тому не потребує прав адміністратора для запису.

## Збірка та запуск із вихідного коду (для розробників)

### Необхідні передумови (Prerequisites)
Для локальної розробки або самостійної збірки релізу в системі мають бути встановлені:
* **Node.js** (рекомендована версія **v20.x** або новіша)
* **npm** (встановлюється разом із Node.js)

### 1. Встановлення залежностей
Клонуйте репозиторій та встановіть залежності для сервера й клієнта:

```bash
git clone https://github.com
cd genshin-character-catalog
npm install
npm --prefix client install
```

### 2. Запуск у режимі розробки (Debug)
У режимі розробки клієнт і сервер запускаються окремо у двох терміналах:

* **Термінал 1 (Запуск Web-API сервера на порту `3001`):**
  ```bash
  npm run server
  ```
* **Термінал 2 (Запуск React GUI у режимі розробки на порту `5173`):**
  ```bash
  npm --prefix client run dev
  ```
* *(Опціонально) Запуск консольного CLI-клієнта для перевірки бізнес-логіки:*
  ```bash
  npm start
  ```

### 3. Повна збірка автономного `.exe` (Release)
Щоб зібрати оптимізований інтерфейс React, об'єднати серверну логіку та запакувати все в єдиний виконуваний файл для Windows, виконайте:

```bash
npm run build
```

Ця команда послідовно виконає:
1. `npm run build:client` — продакшн-збірку React-додатку у папку `client/dist`.
2. `npm run bundle:server` — бандлінг `server.js` та ООП-модулів (`src/`) у `build/server.cjs` за допомогою `esbuild`.
3. `npm run package:exe` — створення готового виконуваного файлу **`release/genshin-character-catalog.exe`** за допомогою `@yao-pkg/pkg`.
